Database & Queries

Database Design & Upsert Query

Guaranteed single log per day and cross-module aggregation for Member 6

Upsert SQL Pattern (SQLite & MySQL)

INSERT INTO mood_entries (user_id, entry_date, mood, symptoms, pain_level, sleep_hours, water_intake)
VALUES (?, ?, ?, ?, ?, ?, ?)
ON CONFLICT(user_id, entry_date) DO UPDATE SET
  mood = excluded.mood,
  symptoms = excluded.symptoms,
  pain_level = excluded.pain_level,
  sleep_hours = excluded.sleep_hours,
  water_intake = excluded.water_intake;

Member 6 Aggregation Query

SELECT COUNT(*) AS total_entries,
       AVG(sleep_hours) AS avg_sleep,
       AVG(water_intake) AS avg_water,
       AVG(pain_level) AS avg_pain
FROM mood_entries WHERE user_id = ?;

Security & Multi-Tenant Isolation

  • Every query is scoped strictly by user_id
  • Parameterized PreparedStatement prevents SQL injection
  • Another user can never see or modify entries
